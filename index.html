全域命理格 OML

人类为「你是谁」这个问题造了几百套坐标系：黄道十二宫、四柱八字、二十七宿、六十四卦、 二十日号、九型、十六型、五因素。它们互相不通话，却在描述同一件事的不同切面。

OML 做的事很简单：把这些体系全部翻译成同一套十二维连续量表， 再由六条双极轴生成一个形如 ROFPWM-3A 的人格代码——结构上与 INTJ-A 同级，信息量却高出两个数量级。

开始 144 题测评 → 浏览 64 型图谱 关系相性计算 世界体系影响力排名

全部计算在你的浏览器本地完成；出生信息与答卷不会离开这台设备。

六个字母

六条双极轴各取显性的一极。六轴即六爻，自下而上，因此每个核心型都恰好对应一个六十四卦—— ROFPWM 即 ☰☲ 天火同人。

一个数字

五行主导：1 木 · 2 火 · 3 土 · 4 金 · 5 水。 由八字五行结构与十二维元素亲和加权合成。

一个后缀

A 协 / T 荡：内部张力与情绪稳态的合成量。 与 16Personalities 的 -A/-T 位置相同，但定义不同（见方法页）。

核心型 2⁶ = 64 种，× 5 行 × 2 调性 = 640 种完整代码； 每个维度同时保留 1–99 的连续分与 95% 区间，代码只是它的可读摘要。

十二维

十二维两两成轴。它们是连续量、且各自独立计分—— 你可以同时高「曜」与高「渊」（能量丰沛），也可以两极同低（低唤起）。字母只表示哪一极更突出。

四层计算

Layer 0

出生信息层

儒略日 → 太阳/月亮黄经、上升点、节气、四柱干支、藏干五行、恒星黄道与二十七宿、卓尔金历、闸门轮。

Layer 1

问卷层

144 题 7 点量表（每维 8 正 4 反），标准化为 z 分，并计算完整度、离散度、默认同意倾向与正反一致性四项效度指标。

Layer 2

象征先验层

十余个符号来源各自映射为十二维偏移向量，按权重合成先验 Bd。权重 λb 由你控制，可以调到 0。

Layer 3

合成与反向映射

Zd = (λqZq + λbB) / √(λq²+λb²)，再反算回 MBTI、大五、九型、依恋、脉轮、体质、塔罗、卢恩、人类图。

世界体系影响力排名（前十）

影响指数 I = 0.40·认知人口 + 0.25·活跃使用 + 0.15·商业规模 + 0.10·制度嵌入 + 0.10·学术支持。 完整 47 项普查见体系普查页。

它不做什么

OML 不预测事件、不判吉凶、不做医疗或心理诊断。它是一套跨体系的翻译层与自我描述工具。 象征层的贡献度在结果页逐项标注，可随时归零。
性别认同、性倾向与关系形态在任何情况下都不参与人格特质推断， 仅用于称谓与关系匹配的意愿准入；传统合婚中一切以性别定吉凶的规则均已对称化改写。
