方法与伦理

OML 的每一步都写在这里。任何一个数字你都可以复算、质疑或替换。

1. 出生信息算法

  • 儒略日：本地民用时按时区折算为 UT，再由 Meeus 标准式得 JD；1582-10-15 起自动切换格里历。
  • 太阳黄经：Meeus ch.25 截断级数（几何平黄经 + 中心差 + 章动/光行差修正），精度 ≈ ±0.01°。
  • 月亮黄经：Meeus ch.47 主要 19 项，精度 ≈ ±0.3°，足以定星座与月相。
  • 上升点：由 GMST + 出生经度得本地恒星时 RAMC，再解 ASC = atan2(−cosRAMC, sinRAMC·cosε + tanφ·sinε)；|纬度| > 66.4° 退化为 MC+90°。
  • 年柱：立春（太阳黄经 315°）换年，不用正月初一。
  • 月柱：以「节」换月，月支由太阳黄经每 30° 一位（寅月起于 315°）；月干由年干五虎遁得出。
  • 日柱：干支序 = (JDN + 49) mod 60。锚点：1949-10-01 = 甲子日，2000-01-01 = 戊午日（见测试）。
  • 时柱：按出生经度做真太阳时校正（偏离时区中央经线 1° ≈ 4 分钟），时干由日干五鼠遁得出；23:00 后按晚子时进位次日。
  • 五行权重：天干各 1.0（日干 1.2），地支藏干按主/中/余气 0.6/0.25/0.15 计并 ×1.2，月令主气再 ×1.5。
  • 吠陀：Lahiri 岁差 ≈ 23.85° + 1.3972°·T 换算恒星黄道，月宿取 27 分位。
  • 其他历法：玛雅卓尔金（GMT 584283 相关数）、人类图 64 闸门轮（Gate 41 起于黄经 302°，标注为近似）、生日卢恩、凯尔特树历、生命灵数。

2. 十二维评分公式

xi  = ki · (ri − 4) / 3   // 单题归一化，k = ±1 为正/反向键，r ∈ [1,7]
Qd = meani∈d xi   // 维度原始分 ∈ [−1, 1]，每维 12 题
Zqd = (Qd − μd) / σd   // 按常模标准化
Bd = 2.4 · Σs ws·vecs[d] / Σs ws   // 象征先验，s 遍历全部符号来源
Zd = (λq·Zqd + λb·Bd) / √(λq² + λb²)   // 保持单位方差的复合
Scored = clamp(round(50 + 15·Zd), 1, 99)

λq 固定为 1，λb ∈ [0, 0.40] 由用户设定（默认 0.15）。λb = 0.15 时象征层约占最终分数的 15%/√(1+0.0225) ≈ 14.8% 的方差贡献；λb = 0 时出生信息完全不影响分数，结果退化为纯心理测量量表。 结果页对每一维标注了「象征占比」，可逐项审计。

3. 十二维与常模

当前常模为设计常模（以量表中点加轻度默认同意偏差为基准的先验值），非实证分层常模。 收集足量真实样本后应替换 src/core/scoring.js 中的 NORMS，并按语言/地区/年龄分层。这是本框架已知的最大局限。

4. OML 代码的构造

  • 六个字母：每条轴取 z 分较高的一极。轴 0→5 依次为初爻→上爻，首极记阳、次极记阴，于是核心型 ≡ 六十四卦（文王卦序）。
  • 数字：五行主导 = 0.35+λb 权重的八字五行结构 与 (1−该权重) 的十二维元素亲和 的加权 argmax。
  • 后缀 A/T：coherence = 0.40·z磐 − 0.35·z汐 + 0.15·z垣 + 0.10·z根 − 0.55·张力 + 0.15·(一致性−0.7)·2， ≥ 0 记 A（协），< 0 记 T（荡）。其中「张力」= 六轴上 min(z极1, z极2) 的均值，度量两极同时偏高造成的内部拉扯。
  • 与 16Personalities 的 -A/-T 的区别：后者的 A/T 基本等价于神经质的反向；OML 的 A/T 额外计入 轴向张力与作答一致性，因此一个情绪敏感但内部自洽的人仍可能是 A。

6. 反向映射

同一组十二维 z 分被线性重述为：MBTI 四轴、大五 OCEAN、九型（余弦相似度 + 侧翼）、成人依恋四象限、 主导脉轮、阿育吠陀三体质、中医体质倾向、人类图四类型（近似）、爱之语排序、四元素亲和、塔罗大阿卡纳原型、卢恩符。 它们是翻译而非第二次测量——不应被当作独立证据来互相印证。

7. 关系相性算法

Total = clamp(round( (wpsy·P + wsym·S) · (0.55 + 0.45·gate) ), 0, 100)

  • gate 准入 = min(意愿A→B, 意愿B→A) × 关系形态相容系数 × (1 − 0.06·节奏差)。仅由自陈的匹配意愿决定，不含任何特质推断。
  • P 心理层：十二维按五种函数加权——趋同型（衡/兆/流/织/垣/化/根）、互补型（曜/渊/锻/流）、争夺型（锻双高扣分）、振幅型（汐，受双方磐的稳态补偿）、联合水平型（磐越高越好）。
  • S 符号层：对称化八字合婚（日支/年支的六合三合冲刑害、日主五行生克、喜用互补）1.2、星盘相位 1.0、MBTI 轴向 0.8、卦象关系（同卦/综卦/错卦/共爻数）0.9、生命灵数 0.5。
  • 权重：wsym = clamp(2·λ̄b, 0, 0.5)，wpsy = 1 − wsym。双方都把 λb 设为 0，符号层就完全不参与。
  • 配对代码：六轴同极记大写、异极记小写（取 A 方字母），后缀为等级 S/A/B/C/D。例：rOFSBm-A。

8. 伦理边界

  • 身份 ≠ 人格。性别认同、性倾向、关系形态、人称代词在任何计算路径上都不作为人格特质的预测变量。它们只用于称谓与关系匹配的双向意愿。
  • 合婚去性别化。传统合婚中依赖「男命/女命」的吉凶条目全部替换为对称规则，使算法对同性、非二元与多元关系同等适用；关系形态相容性作为独立系数显式给出，而不是默认单偶制。
  • 不做外貌推断。面相、手相虽列入体系普查，但明确不纳入计算——基于外貌特征的人格推断具有高度歧视风险。
  • 不做高风险决策。本框架不得用于招聘筛选、信贷、保险、司法或医疗决策。人格量表在选拔场景的效度与公平性问题在学界已有长期争议，而象征层更无此类效度。
  • 数据不出本机。全部计算在浏览器完成，出生信息与答卷仅存于 localStorage，可随时删除；无后端、无遥测。
  • 认识论立场。OML 不主张出生时刻会导致人格差异。象征层的定位是文化语义的翻译通道：它让使用不同体系的人可以谈论同一件事，其默认权重被刻意压到较低，并且可以归零。

9. 已知局限

  • 常模为设计值而非实证分层常模；分数的绝对位置（如「62 分」）目前只有相对意义。
  • 映射系数未经因子分析验证；十二维之间可能存在未建模的相关（当前复合公式假设 ρ = 0）。
  • 天文算法为解析式低精度实现，极区上升点、历史早期日期、时区数据库（未处理夏令时）均为已知薄弱环节；出生时间不确定 ±2 小时可能改变时柱与上升星座。
  • 问卷未做跨语言等值检验；中英文题目为对照翻译而非双向回译验证。
  • 关系相性算法未经纵向追踪验证，不能预测关系存续。
