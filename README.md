# OML · 全域命理格 / Omni-Mantic Lattice

**把世界各地的命理体系与现代人格分类统一到同一套十二维连续量表，生成形如 `ROFPWM-3A` 的人格代码。**

人类为「你是谁」这个问题造了几百套坐标系：黄道十二宫、四柱八字、二十七宿、六十四卦、二十日号、
九型、十六型、五因素。它们互相不通话，却在描述同一件事的不同切面。
OML 把它们全部翻译成同一套坐标，再由六条双极轴生成一个与 `INTJ-A` 同级、信息量高两个数量级的代码。

零依赖、零后端、全部计算在浏览器本地完成。

**在线体验：https://dirtycomputer.github.io/compute-lunar-claude/**

## OML 代码怎么读

```
R O F P W M - 3 A
└─────┬────┘   │ │
   六条轴的显性极  │ └── 调性：A 协 Attuned / T 荡 Turbulent
                └──── 五行主导：1木 2火 3土 4金 5水
```

- **六个字母**：六条双极轴各取显性一极。六轴即六爻（轴 0 为初爻），
  因此**每个核心型恰好对应一个六十四卦**——`ROFPWM` = 风火家人。
- **一个数字**：五行主导，由八字五行结构与十二维元素亲和加权合成。
- **一个后缀**：`A` 协 / `T` 荡，由情绪稳态、轴向内部张力与作答一致性合成。

代码空间：**64 × 5 × 2 = 640 种**。每一维同时保留 1–99 的连续分与 95% 区间，代码只是它的可读摘要。

### 十二维

| 轴 | 极 A | 极 B |
|---|---|---|
| 能量 | **R 曜** Radiance 外放 | **D 渊** Depth 内沉 |
| 认知 | **L 衡** Ledger 实证 | **O 兆** Omen 象征 |
| 意志 | **F 锻** Forge 掌控 | **C 流** Current 顺势 |
| 情感 | **P 汐** Pulse 振幅 | **S 磐** Stone 稳态 |
| 联结 | **W 织** Weave 联结 | **B 垣** Bastion 边界 |
| 生成 | **M 化** Meta 变易 | **G 根** Ground 承续 |

十二维**各自独立计分**——你可以同时高「曜」与高「渊」（能量丰沛），也可以两极同低。
「两极同高」会计入内部张力并影响 A/T 后缀，这是四轴二分模型结构上无法表达的信息。

## 四层计算

```
x_i     = k_i · (r_i − 4) / 3                      单题归一化（k = ±1 为正/反向键）
Q_d     = mean_{i∈d} x_i                           维度原始分 ∈ [−1, 1]
Zq_d    = (Q_d − μ_d) / σ_d                        按常模标准化
B_d     = 2.4 · Σ_s w_s·vec_s[d] / Σ_s w_s         象征先验（14 个符号来源加权）
Z_d     = (λq·Zq_d + λb·B_d) / √(λq² + λb²)        保持单位方差的复合
Score_d = clamp(round(50 + 15·Z_d), 1, 99)
```

- **Layer 0 出生信息**：儒略日 → 太阳/月亮黄经、上升点、节气、四柱干支、藏干五行、
  恒星黄道与二十七宿、卓尔金历、闸门轮。全部解析式实现，零星历文件。
- **Layer 1 问卷**：144 题（12 维 × 12 题，8 正 4 反）+ 四项效度指标。
- **Layer 2 象征先验**：14 个来源各映射为十二维偏移向量。
  **权重 λb 由用户控制（默认 0.15，可归零）**。
- **Layer 3 合成与反向映射**：反算 MBTI、大五、九型、依恋、脉轮、阿育吠陀、中医体质、
  人类图、爱之语、四元素亲和、塔罗、卢恩。

## 关系相性

```
Total = clamp( round( (w_psy·P + w_sym·S) · (0.55 + 0.45·gate) ), 0, 100 )
```

- **准入 gate**：双向匹配意愿 × 关系形态相容 × 节奏差。只处理「是否愿意」，不做身份推断。
- **心理层 P**：十二维按五种函数计分——趋同型、互补型、争夺型、振幅型、联合水平型。
- **符号层 S**：对称化八字合婚、星盘相位、MBTI 轴向、卦象关系（综卦/错卦）、生命灵数。
- **配对代码**：同极大写、异极小写 + 等级，如 `rOFSBm-A`。

## 伦理约束（用测试兑现，不只是声明）

> **身份 ≠ 人格。** 性别认同、性倾向、关系形态在任何计算路径上都不作为人格特质的预测变量。

| 约束 | 测试断言 |
|---|---|
| 性别认同不进入维度分与代码 | 遍历 9 种性别认同，十二维分数与代码**逐位相等** |
| 性倾向标签不改变相性分 | 遍历 8 种标签，相性总分**完全相同** |
| 同性/异性/非二元配对同分 | 相同人格下四种配对**总分与配对代码完全一致** |
| 合婚规则对称、去性别化 | `baziAffinity(A,B) === baziAffinity(B,A)`，交换性别标签结果不变 |
| λb = 0 时出生信息严格无影响 | 换一个完全不同的生日，十二维分数逐位相等 |

传统合婚中一切以性别定吉凶的条目均已替换为对称规则。
不做外貌推断（面相/手相列入普查但不纳入计算）。不用于招聘、信贷、保险、司法或医疗决策。
详见 [docs/05-ethics-inclusion.md](docs/05-ethics-inclusion.md)。

## 已知局限

- **常模是设计值而非实证分层常模**：分数的相对结构可靠，绝对位置（「62 分」超过多少人）尚无实证含义。
- 映射系数是设计参数，未经因子分析验证；复合公式假设问卷分与象征先验不相关（ρ = 0）。
- 天文算法为低精度解析式；未处理夏令时与历史时区变迁；极区上升点退化处理。
- 问卷中英文为对照翻译，未做双向回译等值检验。
- 关系相性算法未经纵向追踪验证，不能预测关系存续。
