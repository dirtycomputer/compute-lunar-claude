# 04 · 关系相性算法

实现：`src/core/matching.js`　页面：[pair.html](../pair.html)

```
Total = clamp( round( (w_psy·P + w_sym·S) · (0.55 + 0.45·gate) ), 0, 100 )
```

四层：**准入 gate → 心理层 P → 符号层 S → 合成**。

---

## 0. 准入层 Gate

准入层只回答一个问题：**双方是否愿意被匹配**。它不对身份做任何特质推断。

```
gate = min(意愿_A→B, 意愿_B→A) × 关系形态相容系数 × (1 − 0.06 × 节奏差)
```

**单向意愿**：A 的「希望被匹配的性别」列表若包含 B 的性别桶（或含 `any`）记 1；
含 `none`（暂不寻求）记 0；B 未透露性别记 0.8（不阻断，仅轻微折减）。

性别桶做最小归并（`woman | man | nonbinary | unknown`），跨性别女性归入 woman、跨性别男性归入 man、
性别流动/无性别/间性/探索中归入 nonbinary。**这个归并只用于匹配意愿的集合运算**，
不参与任何特质计算，也不构成对身份的定义。

**关系形态相容系数**（对称矩阵）：

| | 单偶 | 开放 | 多元 | QPR | 未定 |
|---|---|---|---|---|---|
| 单偶 mono | 1.00 | 0.60 | 0.45 | 0.80 | 0.85 |
| 开放 open | 0.60 | 1.00 | 0.90 | 0.85 | 0.85 |
| 多元 poly | 0.45 | 0.90 | 1.00 | 0.85 | 0.85 |
| QPR | 0.80 | 0.85 | 0.85 | 1.00 | 0.90 |
| 未定 undecided | 0.85 | 0.85 | 0.85 | 0.90 | 0.90 |

系数 < 0.70 时输出协商提示，而不是把关系判为不可行。

**伙伴模式**：`mode: 'partner'` 时 gate 取 max(gate, 0.9)，用于评估合作/友谊相性——
这样「不互相匹配」的两个人仍能看到有意义的协作结构。

## 1. 心理层 P

十二维各按一种函数计分（0–100），再加权平均。z 为双方各维的 z 分。

| 函数 | 公式 | 用于 | 理由 |
|---|---|---|---|
| **趋同型 sim** | `100 − 22·Δ` | 衡 兆 流 织 垣 化 根 | 世界观、亲密需求量、生活节奏——差距越小摩擦越小 |
| **互补型 comp** | `100 − 30·\|Δ − 0.9\| − 6·max(0, Δ−2.2)` | 曜 渊 | 能量方向在**中等差距**处最优：完全一样会互相耗尽，差太远会失联 |
| **争夺型 clash** | `100 − 16·Δ − 26·max(0, min(z_A,z_B) − 0.4)` | 锻 | 掌控欲双高会争主导权，这是差距之外的独立扣分项 |
| **振幅型 volatility** | `100 − 18·Δ − 22·max(0, 均值−0.3) + 14·稳态` | 汐 | 双方情绪振幅都高时不稳，但可被双方的「磐」补偿 |
| **联合水平型 joint-high** | `55 + 20·均值 + 8·(1−min(1,Δ)) − 10·max(0,−最高值)` | 磐 | 情绪稳态是关系地基，**双方都高**才好，不看差距 |

权重：织 1.3 > 锻 = 化 = 根 = 磐 1.2 > 兆 1.1 > 曜 = 衡 = 垣 1.0 > 渊 = 流 0.8。

**为什么「织」权重最高**：亲密需求量的错配（一方要每天在一起、另一方要每周两次）
是长期关系里最难协商的结构性差异之一——它不像价值观分歧那样可以讨论，也不像兴趣差异那样可以各玩各的。

| 项 | 权重 | 内容 |
|---|---|---|

### 2.1 八字合婚的对称化改写

传统合婚中有大量以性别决定吉凶的条目（「男怕…女怕…」「女命伤官克夫」之类）。
这类规则在算法里无法既保留又保持公平，因此 **OML 全部替换为对称规则**：

| 关系 | 分值 | 说明 |
|---|---|---|
| 六合 | +3.0 | |
| 三合（带中神） / 半合 | +2.5 / +1.5 | |
| 同支比和 | +1.0 | |
| 六冲 | −3.0 | |
| 相刑 | −2.0 | |
| 相害 | −1.5 | |
| 日主相生（**任一方向**） | +2.5 | 传统会区分「谁生谁」并据此论主从，此处不区分 |
| 日主比和 | +1.2 | 同气相求，易懂但少张力 |
| 日主相克（**任一方向**） | −1.8 | 记为「需要明确的权力协商」，不记为凶 |
| 喜用互补（单向各计） | +1.5 | 一方的旺气恰是另一方的喜用 |

测试断言：`baziAffinity(A, B) === baziAffinity(B, A)`，且交换双方性别标签结果不变。

### 2.2 星盘相位

容许度：合相 12°、三分相 8°、六分相 6°、四分相 7°、对分相 9°。
分值：三分 +14、合相 +12、六分 +10、对分 +4、四分 −6。
元素关系：互助元素（火风 / 土水）+11、同元素 +9、张力元素 −4。

### 2.3 卦象关系

两人的核心型各对应一卦。**综卦**（六爻倒转）得分最高（88）——
它意味着两人是「同一件事的两端」，视角天然互补；**错卦**（阴阳全反）次之（82），
吸引力强但磨合成本高；**同卦**（74）理解成本最低，但共享同一个盲区。

## 3. 合成与输出

```
w_sym = clamp(2 · mean(λb_A, λb_B), 0, 0.5)
w_psy = 1 − w_sym
```

**双方都把 λb 设为 0 时，符号层完全不参与总分**（有测试断言）。默认 λb = 0.15 → w_sym = 0.30。

### 3.1 五项子分

| 子分 | 构成 | 读法 |
|---|---|---|
| 共鸣 Resonance | 兆 衡 织 根 的均值 | 世界观与亲密需求的同频程度 |
| 互补 Complement | 曜 渊 锻 流 的均值 | 能量与掌控方式的错位是否恰到好处 |
| 稳态 Stability | 0.6·(磐 汐 均值) + 0.4·(50 + 15·双方磐均值) | 关系的情绪地基 |
| 成长 Growth | 0.5·(化 兆 均值) + 0.5·变化取向的联合项 | 一起变化的潜力 |
| 张力 Friction | 100 − (锻 垣 汐 的均值) | **数值越高摩擦越强，不等于坏** |

### 3.2 关系原型

| 条件 | 原型 |
|---|---|
| 六轴同极 ≥ 5 | 同源镜像 Mirror Pair — 理解成本极低，盲区重叠 |
| 六轴同极 ≤ 1 | 两极互补 Polar Complement — 吸引力强，翻译成本高 |
| 互补 ≥ 72 且共鸣 ≥ 68 | 共振互补 Resonant Complement — 长期关系最稳的结构之一 |
| 共鸣 ≥ 75 | 同频共同体 Kindred Commune — 易共同生活，注意共同停滞 |
| 张力 ≥ 55 | 张力锻造 Forged in Friction — 摩擦是主要能量来源 |
| 其余 | 缓冲互织 Woven Buffer |

### 3.3 依恋组合

十种组合各有一条具体建议（如「焦虑 + 回避」的追–逃循环需要显式的暂停与回归约定）。
依恋类型由十二维反算（见 docs/03 §5.3），不需要额外量表。

### 3.4 配对代码

六轴逐位比较：同极记大写，异极记 A 方字母的小写；后缀为等级。

```
rOFSBm-A    ← 轴 0、5 异极，轴 1–4 同极，等级 A
```

等级阈值：S ≥ 88、A ≥ 78、B ≥ 66、C ≥ 52、D < 52。

## 4. 算法的已知边界

- **未经纵向验证**：本算法从未用真实的关系存续数据校准过。它能告诉你「哪些地方需要显式约定」，
  不能告诉你「这段关系能不能成」。
- **对称但非完备**：算法只处理两人。多元关系（poly）目前只能两两计算，
  不建模三人及以上的网络结构。
- **文化偏置**：「趋同/互补」的分配（比如认为价值观应趋同、能量应互补）来自当代都市亲密关系的假设，
  在其他婚配文化中未必成立。
- **不做筛选**：算法的定位是**沟通起点**。任何把相性分当作交往门槛的用法都超出了它的效度范围。
