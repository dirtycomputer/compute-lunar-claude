# 01 · 世界命理与人格分类体系普查与影响力排名

> 本文是 OML 的前置工作：在设计一个统一体系之前，先把要统一的对象数清楚。
> 共收录 **47 个体系**，覆盖六大洲、约三千年，并给出一个透明可复算的影响力指数。

---

## 1. 为什么需要排名，以及排名的诚实边界

「哪个命理体系影响力最大」没有权威答案：没有全球普查，没有统一的注册从业者名录，各体系的「使用」定义也完全不同——
一个人可能天天看星座却从不付费，另一个人一生只算过一次八字却据此决定了婚姻。

因此本文不假装给出实测数据，而是把判断显式化为**五个可分别质疑的子分**，再用固定权重合成：

```
影响指数 I = 0.40·认知人口 + 0.25·活跃使用 + 0.15·商业规模 + 0.10·制度嵌入 + 0.10·学术支持
```

| 子分 | 含义 | 判断依据 |
|---|---|---|
| 认知人口 | 有多少人**知道**这套体系，并能说出自己在其中的类别 | 覆盖人口的量级、公共话语中的出现频率 |
| 活跃使用 | 有多少人**在用它做决定**（择日、择偶、择业、自我理解） | 使用场景的深度与频次 |
| 商业规模 | 围绕它形成的付费市场 | 从业者规模、应用与内容产业的可见度 |
| 制度嵌入 | 是否进入了正式制度（婚配惯例、企业人事、教育、医疗） | 制度性使用的证据 |
| 学术支持 | 同行评议文献中的效度证据 | 是否被主流学界当作可测量的构念 |

这些子分是 **order-of-magnitude judgement（量级判断）**，不是统计量。它们的价值在于可被逐项反驳：
如果你认为「风水的商业规模应该是 90 而不是 82」，改一个数字重排即可——数据结构就是接口
（`src/data/systems.js`，网页版可点表头重排：[systems.html](../systems.html)）。

**权重本身也是立场。** 把「学术支持」的权重从 0.10 提到 0.50，大五人格会跃居第一而占星会大幅下滑；
把「认知人口」提到 0.70，生肖会逼近榜首。当前权重刻意偏向「有多少人的自我理解被它塑造」，
而不是「哪个更真」——因为后者会让这张表退化成一句「除了心理测量以外全部为零」，那就没有普查的意义了。

## 2. 五个体系族

收录的 47 个体系分为五族。分族的意义在于：**它们回答的不是同一个问题**，因此不能直接比较真伪。

| 族 | 数量 | 输入 | 认识论主张 | 代表 |
|---|---|---|---|---|
| **传统命理/占卜** divination | 25 | 出生时刻、随机事件、身体特征 | 时空结构与人事同构 | 占星、八字、塔罗、易经、伊法 |
| **现代心理测量** psychometric | 8 | 自陈问卷 | 特质是可测量的连续变量 | 大五、MBTI、九型、依恋 |
| **流行文化分类** popculture | 5 | 混合 | 主要功能是社交货币与自我叙事 | 血型、16Personalities、性格色彩 |
| **体质/医学传统** somatic | 4 | 体征与问诊 | 体质决定倾向 | 阿育吠陀、中医体质、藏医 |
| **身份自述框架** identity | 2 | 纯自陈 | 身份是自我定义而非被推断的 | 金赛量表、性别谱系 |

第五族是本普查刻意加入的。金赛量表、克莱因方格、分离吸引模型、性别认同/表达的分离模型
在形式上也是「分类学」，也生成标签（双性恋、非二元、无性恋谱系），也深刻塑造自我理解，
所以它们属于同一张普查表。但它们与前四族有一个根本区别，这个区别构成 OML 的核心伦理约束：

> **前四族宣称「你的类别可以由外部信息推断出来」；第五族宣称「你的类别只能由你自己声明」。**

因此在 OML 中，第五族的字段永远只作为**身份与匹配意愿**存在，绝不作为人格特质的预测变量。
详见 [05-ethics-inclusion.md](05-ethics-inclusion.md)。

## 3. 榜单要点

1. **MBTI（77.2）与西洋占星（74.5）并列第一梯队。** 一个来自 20 世纪的心理学商业化，一个来自公元前两千纪的天文观测，
   却在同一个位置：都是全球性的、日常语言级的、可以在社交场合直接报代码的自我标签。OML 的代码形式
   （`ROFPWM-3A`，六字母 + 修饰后缀）正是对这两者交汇处的直接继承。
2. **生肖（68.6）是被严重低估的第一名候选。** 它的认知人口几乎是所有体系里最高的（东亚 + 全球华人 + 拉美与欧美的文化输出），
   只是「使用深度」低——大多数人知道自己属什么，但不据此决策。
3. **传统命理的商业规模普遍高于其学术支持两个数量级。** 风水（商业 82 / 学术 8）、八字（78 / 8）、
   吠陀占星（72 / 10）。这不是反驳，而是一个需要被算法诚实反映的事实：
   OML 把象征层的默认权重压到 λb = 0.15，并允许归零。
4. **制度嵌入的冠军是吠陀占星（72）**，因为南亚的婚配合盘（Kundali Milan）仍是大量婚姻的实际前置程序；
   其次是 MBTI（62）与霍兰德（62），它们进入了企业人事与教育体系。这三个体系的共同点是：
   **它们的分类结果会改变别人对你的对待方式**——这正是最需要伦理约束的场景。
5. **二元占卜是一个跨文明的独立发现。** 中国的六十四卦（2⁶）、西非约鲁巴的 256 奥杜（16×16 = 2⁸）、
   阿拉伯沙占的十六图（2⁴）、马达加斯加的 sikidy——彼此独立发展出「用二进制枚举可能状态」的结构。
   OML 的六轴极性正是这一族的直接后裔：**六条双极轴 = 六爻 = 64 型**，这不是附会，而是同一种组合学。

## 5. 未收录与刻意排除

- **面相、手相**：已收录进普查表（列出即可比较），但**明确不纳入 OML 的计算**。基于外貌特征推断人格的技术
  在历史上直接服务过种族与阶级歧视，且现代「AI 面相」的复现使其风险不减反增。
- **占卜性事件预测**（六壬、奇门、择日、多数塔罗牌阵）：输入是「此刻的随机事件」而非「这个人」，
  与人格测量不同构，只在普查中列出。
- **风水**：对象是空间而不是人，同上。
- **药轮/图腾体系**：北美原住民传统的商业化改写存在严重的文化挪用争议，且各部族传统差异极大，
  不存在可以被安全「统一映射」的单一体系。OML 只列入普查，不做映射。
- **各类未成体系的网络测验**（星座配对小游戏、性格测色等）：数量无穷且无稳定定义。

## 6. 参考与方法说明

本文的子分为综合判断，主要参考类型包括：各体系的规模与市场公开报道、应用与搜索的可见度、
婚配与人事制度中的使用惯例、以及同行评议文献的存在量。本文**不逐条引用具体来源**，
因为任何单一来源都不足以支撑全球量级的断言；这也是把判断拆成五个可分别反驳的子分、
并把数据与权重完全开放的原因。

如果你有更好的数据，正确的做法不是相信这张表，而是改掉它：
修改 `src/data/systems.js` 中的子分或 `WEIGHTS`，运行 `node scripts/gen-ranking.js` 重新生成本表。
