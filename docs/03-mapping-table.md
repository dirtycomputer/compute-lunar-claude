# 03 · 统一映射表：八字 / 星盘 / MBTI / 其余体系 ↔ OML 十二维

映射分两个方向：

- **正向**（符号 → 十二维）：离散符号被翻译成十二维上的 z 偏移向量，按权重合成象征先验 B_d，再经 λb 缩放注入分数。
- **反向**（十二维 → 符号）：同一组 z 分被线性重述为其他体系的语言。**这是翻译，不是第二次测量**，
  不能用来「互相印证」。

所有数值单位为 z（标准差），实现见 `src/core/mapping.js`。

## 4. MBTI ↔ 十二维（双向）

### 4.1 正向（自陈 MBTI → 十二维，权重 0.90）

| 字母 | 向量 |
|---|---|
| E / I | 曜 ±0.80、渊 ∓0.60 |
| S / N | S: 衡 +0.70、兆 −0.50、根 +0.30 ／ N: 兆 +0.80、化 +0.40、衡 −0.40 |
| T / F | T: 衡 +0.50、垣 +0.40、汐 −0.40 ／ F: 织 +0.60、汐 +0.50、垣 −0.30 |
| J / P | J: 根 +0.50、衡 +0.40、流 −0.50 ／ P: 流 +0.60、化 +0.50、根 −0.40 |

### 4.2 反向（十二维 → MBTI）

```
E/I ← 0.70·z曜 − 0.50·z渊
N/S ← 0.65·z兆 − 0.55·z衡 + 0.20·z化
F/T ← 0.55·z织 + 0.45·z汐 − 0.40·z衡 − 0.35·z垣
P/J ← 0.55·z流 + 0.40·z化 − 0.45·z根 − 0.30·z衡
```

每轴另给百分位与「轴向清晰度」。**清晰度 < 40% 时该字母不稳定**——
这正是 OML 优于四轴二分模型的地方：MBTI 会把 51:49 和 95:5 输出成同一个字母，OML 把这个差别显式保留。

### 4.3 结构对照

| | MBTI | OML |
|---|---|---|
| 轴数 | 4 | 6 |
| 类型数 | 16 | 64（× 5 × 2 = 640） |
| 每轴信息 | 二分类 | 两个独立连续维（可同高/同低） |
| 「两极同高」 | 无法表达 | 计入张力，影响 A/T 后缀 |
| 出生信息 | 无 | 可选，权重可归零 |

## 7. 使用这张表时的三条纪律

1. **不要把反向映射当成第二次测量。** 「OML 说我是 INFP，MBTI 也说我是 INFP，所以互相印证」是循环论证——
   反向映射本来就是同一组分数的重述。
2. **不要跨方向叠加。** 用自陈 MBTI 作先验（正向）、又用反向映射得到 MBTI，两者必然相关，不构成独立证据。
3. **系数是设计参数不是发现。** 它们保证翻译的一致性与可复算性，不宣称任何因果关系。
